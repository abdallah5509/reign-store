## ⚡ طرق التشغيل

### 1. التشغيل المحلي الفوري (بنقرة واحدة)
* اضغط مرتين على ملف:
  ```
  start_reign.bat
  ```
* سيفتح المتجر تلقائياً في متصفحك على:
  👉 **http://localhost:8080**
* لوحة تحكم المتجر:
  👉 **http://localhost:8080/admin.html** (الرمز السري الافتراضي PIN: `1234`)

### 2. النشر المباشر أونلاين برابط عام (Live URL)
* اضغط مرتين على ملف:
  ```
  start_online.bat
  ```
* سيتم إنشاء نفق سحابي عبر `cloudflared` ومنحك رابطاً علنياً مباشراً لمشاركته وتجربته على الموبايل من أي مكان فوراً!

### 3. الرفع على GitHub (حسابك: `abdallah5509`)
المستودع مهيأ ومربوط مسبقاً، يمكنك تشغيل الأوامر التالية لإنشاء المستودع ورفعه:
```bash
git remote add origin https://github.com/abdallah5509/reign-store.git
git branch -M main
git push -u origin main
```

## 🌟 مميزات متجر REIGN

1. **تصميم تحريري إنساني وواقعي (Humanistic & High-End Aesthetic):**
   - تم استخدام الصور الحقيقية المستخرجة من جلسات تصوير براند REIGN الرسمية (بدون أي صور مولدة أو طابع آلي).
   - اعتماد الشعار الأصلي الدائري للبراند بخلفية الساتان الفاخرة وتاج REIGN المميز.
   - خطوط عصرية جريئة تجمع بين العربية الحادة (`Alexandria`) والإنجليزية الرياضية الفاخرة (`Outfit` و `Space Grotesk`).

2. **محول الألوان التفاعلي (Interactive Color Switcher):**
   - إمكانية التبديل بنقرة واحدة بين الألوان الثلاثة الحقيقية للبناطيل:
     - **Onyx Black** (أسود نفاث)
     - **Heather Grey** (رمادي فاتح ميلانج)
     - **Charcoal Slate** (رمادي داكن شاركول)
   - كل لون يعرض مباشرة صورته الحقيقية وانسدال القماش الواقعي من جلسة التصوير.

3. **دليل المقاسات التفاعلي (Interactive Size Guide):**
   - جدول مقاسات ذكي يوضح المقاس الأنسب (S, M, L, XL, XXL) حسب الوزن والطول ومحيط الخصر.
   - نصائح لاختيار الـ Baggy Fit أو الـ Regular Fit.

4. **سلة شراء منبثقة ذكية (Slide-in Drawer Cart):**
   - حساب فوري وتلقائي لمصاريف الشحن حسب المحافظة:
     - القاهرة والجيزة (50 ج.م)
     - الإسكندرية ومحافظات الدلتا (60 ج.م)
     - محافظات الصعيد والبحر الأحمر (75 ج.م)
   - شحن مجاني تلقائي عند الوصول للحد الأدنى (1500 ج.م).

5. **إتمام الطلب التلقائي عبر واتساب (WhatsApp Direct Checkout):**
   - توليد رسالة واتساب احترافية منسقة بكافة تفاصيل المنتجات، الألوان، المقاسات، والإجمالي، وتوجيه العميل مباشرة لرقم الواتساب: `01277141615`.

6. **لوحة تحكم الإدارة (Admin Panel):**
   - عبر الرابط `/admin.html` مع قفل أمان برمز PIN.
   - تعديل الأسعار فوراً بدون لمس الأكواد.
   - تحديث رقم الواتساب المستلم وأسعار الشحن للمحافظات.
   - متابعة وتحديث سجل الطلبات الواردة.
